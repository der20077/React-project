# 🌗 Переключение темы (Styled Components + localStorage)

Демонстрация работы с темами в React с использованием Styled Components и сохранением выбора пользователя в localStorage.

## 🧩 Функционал

- Переключение светлой / тёмной темы
- Сохранение выбранной темы в localStorage
- Глобальные стили через `createGlobalStyle`
- Плавный переход между темами

## 🛠️ Использованные технологии

- React (useState)
- Styled Components (ThemeProvider, GlobalStyle)
- localStorage
- Vite
