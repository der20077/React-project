# ⚛️ useTransition — плавные обновления в React

Демонстрация работы хука `useTransition` для оптимизации производительности при тяжёлых обновлениях UI.

---

## 🧩 Что внутри

### ✅ Базовый пример
- Простое увеличение счётчика через `startTransition`
- Отображение состояния `isPending`

### ✅ Фильтрация большого списка (10 000 элементов)
- Поиск с плавным обновлением
- `useTransition` для предотвращения подвисаний интерфейса
- Индикатор загрузки во время фильтрации

### ✅ Медленный рендеринг (50 000 элементов)
- Генерация большого списка при вводе текста
- Использование `startTransition` для фонового обновления
- Сохранение отзывчивости интерфейса

### ✅ Переключение вкладок (TabExample)
- Ленивая загрузка тяжёлого компонента (`AboutTab`)
- `memo` для оптимизации ре-рендеров
- Имитация медленных операций через цикл задержки

---

## 🛠️ Использованные технологии

- React (`useState`, `useTransition`, `memo`)
- Оптимизация производительности
- Имитация тяжёлых вычислений
