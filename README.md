# 📝 Todo App (React + Tailwind CSS)

Полноценное Todo-приложение с поддержкой тёмной темы, анимациями и адаптивным дизайном.

---

## 🧩 Функционал

- ✅ Добавление задач
- ✅ Удаление задач (с анимацией появления кнопки при наведении)
- ✅ Отметка о выполнении (чекбокс с анимацией)
- ✅ Тёмная / светлая тема (переключение через toggle)
- ✅ Автоматическое определение темы:
  - Системные настройки (`prefers-color-scheme`)
  - Время суток (с 21:00 до 6:00 — тёмная)
  - Сохранение выбора в `localStorage`
- ✅ Адаптивный дизайн
- ✅ Плавные анимации (hover, переходы)

---

## 🛠️ Использованные технологии

- React (хуки: `useState`)
- Tailwind CSS (v4)
- Кастомные CSS-переменные для темы
- `localStorage` для сохранения темы

---

## 📌 Особенности
- Кнопка удаления появляется только при наведении на задачу
- Чекбокс с анимацией заполнения
- Градиентный заголовок
- Тёмная тема с плавным переключением
