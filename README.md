# 🛠️ Кастомные хуки с useDebugValue

Демонстрация использования `useDebugValue` для отладки кастомных хуков в React.

---

## 🧩 Что внутри

- ✅ `useApi` — работа с API (axios) + `useDebugValue`
- ✅ `useForm` — управление формами + `useDebugValue`
- ✅ `useLocalStorage` — работа с localStorage + `useDebugValue`

---

## 🔍 useDebugValue

`useDebugValue` — это хук для отладки кастомных хуков в React DevTools.

Он позволяет:
- Показывать значения хуков в DevTools
- Форматировать вывод для удобства
- Использовать только в режиме разработки

---

## 🛠️ Использованные технологии
React (хуки: useState, useCallback, useEffect, useDebugValue)

Axios

localStorage
