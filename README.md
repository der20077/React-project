# 🧑‍🤝‍🧑 UserList

Компонент для отображения списка (пользователей с хобби).

## 🧩 Использованные навыки

- React (функциональные компоненты, пропсы)
- Рендеринг списков (`map`)
- Условный рендеринг (тернарный оператор)
- Вложенные списки
- Правильное использование `key`
- Стилизация через **SCSS** (в отдельном файле)
- БЭМ-нейминг
- Анимация при наведении

## 📂 Структура

- `HomePage.jsx` — логика компонента
- `HomePage.scss` — стили (SCSS)

## 🚀 Пример использования

```jsx
const users = [
  { id: 1, name: "Анна", age: 25, hobbies: ["Чтение", "Путешествия"] },
  { id: 2, name: "Борис", age: 30, hobbies: [] },
];

<UserList users={users} />
