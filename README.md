# 📝 React Forms with Custom Hook

Демонстрация использования кастомного хука `useForm` для управления формами в React.

---

## 🧩 Функционал

- ✅ Авторизация (логин)
- ✅ Регистрация
- ✅ Управление данными форм через кастомный хук
- ✅ Обработка отправки данных
- ✅ Переиспользуемые компоненты форм

---

## 🛠️ Использованные технологии

- React (хуки: `useState`)
- Кастомный хук `useForm`
- Компонентный подход
