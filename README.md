# ⚛️ React useReducer — Todo + Counter

Демонстрация использования хука `useReducer` для управления состоянием в React.

---

## 🧩 Что внутри

### ✅ Todo-лист
- Добавление задач (`ADD_TODO`)
- Переключение статуса выполнения (`TOGGLE_TODO`)
- Автоматическая генерация `id` через `Date.now()`

### ✅ Счётчик
- Увеличение / уменьшение (`INCREMENT` / `DECREMENT`)
- Установка значения через input (`SET_VALUE`)
- Сброс (`RESET`)

---

## 🛠️ Использованные технологии

- React (`useReducer`, `useState`)
- Кастомные редьюсеры
