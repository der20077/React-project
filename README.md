# 📝 Форма регистрации (React)

Полноценная форма регистрации с валидацией на React.

---

## 🧩 Функционал

- Поля: Имя, Email, Пароль, Подтверждение пароля, Год окончания учебного заведения
- Валидация пароля (минимум 8 символов, латиница + цифры)
- Проверка совпадения паролей в реальном времени
- Все поля обязательны для заполнения
- Визуальная обратная связь (ошибки, успешная отправка)
- Кнопка "Очистить форму" (сброс всех полей)
- Кнопка "Отправить" (вывод данных в alert)

---

## 🛠️ Использованные React-приёмы

- Функциональные компоненты
- Хуки (`useState`)
- Управляемые компоненты
- Условный рендеринг
- Обработка событий (`onChange`, `onSubmit`, `onReset`)
- Динамический рендеринг списков (`select` с годами)
- Разделение логики и UI (валидаторы в отдельном файле)

---

## 🧪 Валидаторы (`validators.js`)

| Функция | Описание |
|---------|----------|
| `validatePassword(password)` | Проверяет пароль: минимум 8 символов, латиница + цифры |
| `checkPasswordMatch(password, confirmPassword)` | Проверяет совпадение паролей |
| `checkRequired(fields)` | Проверяет, что все поля заполнены |
